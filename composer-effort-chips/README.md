# 快捷挂档（composer-effort-chips）

把输入框（composer）工具栏里的「推理强度 / effort」从两级下拉菜单平铺成一排可直点的档位胶囊，放在发送按钮左侧——像挂档一样一键切换。模型选择仍用系统自带的选择器，本插件不碰它。

## 功能

- 在发送按钮左侧渲染当前模型可用的全部 effort 档位（含「默认」档，仅当提供方未固定默认值时出现）
- 当前档高亮；点任意档位一键切换，对下一次请求生效（与系统行为一致）
- 已冻结系统选择器触发按钮的宽度（176px），切档时工具栏不再左右抖动
- 子代理会话自动隐藏；composer 锁定或选择进行中时禁用

## 实现说明

- 注册到 `conversation.input.right` 槽位（列表型，与内置 UI 叠加，不抢占）
- 数据走内置 `ui-model-selection` 插件的 `modelDirectories` 服务，选择动作与其完全同源
- 冻结宽度的样式带 `data-plugin` 标记，卸载即移除

## 已知取舍

- 档位来自模型适配器公布值；适配器无推理元数据时不显示任何档位（与内置行为一致）
- 长模型名在 176px 内可能显示省略号，可改 `client.js` 中冻结样式的宽度

## 卸载

`plugin_manager` 移除 `@local/composer-effort-chips` 即恢复原状。
